# Explorador 3D Interactivo de Walter para Ideum
Aplicación interactiva para explorar el modelo 3D de Walter y sus componentes en una mesa táctil Ideum.

## Requisitos

- Node.js 24.16.0
- npm
- Git

## Instalación y ejecución local

```bash
git clone URL_DEL_REPOSITORIO
cd NOMBRE_DEL_PROYECTO
